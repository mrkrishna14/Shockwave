Register a Shockwave demo GitHub App from its manifest

Local helper for GitHub's documented manifest flow (see demo/github/docs-verified.json, entry manifest-flow). It sends the manifest you paste to GitHub only, after you press the button. It stores nothing, installs nothing and talks to no other server.

Shockwave hackathon demo. Register the app under the same account that owns the private consumer repositories: an app with "public": false can only be installed on the account that owns it. After you click "Create GitHub App" on GitHub, GitHub redirects to the manifest's redirect_url with ?code=...&state=.... With the shockwave.example.invalid placeholders that page cannot load, but the address bar still shows the code. Exchange it within one hour (demo/GITHUB_SETUP.md) and keep the returned secrets outside the repository.
